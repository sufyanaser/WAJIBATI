High-level system architecture of WAJIBATI (واجباتي — إعدادية الرميلة للبنين), a mobile-first Progressive Web App (PWA) designed for daily school homework distribution, notices, and Web Push notifications in Ramadi, Anbar, Iraq. The frontend is built on Vite, React 18, and TypeScript, backed by Supabase for authentication, PostgreSQL persistence with fine-grained Row-Level Security (RLS), private/public asset storage, and Deno Edge Functions for serverless push fan-out and guardian provisioning.
