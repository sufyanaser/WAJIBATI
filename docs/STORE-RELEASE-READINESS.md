# Wajibati — Store Release Readiness

Owner (intended): Raneen (legal incorporation pending).
Publisher contact: biz@raneen.cc.
Target stores: Google Play and Apple App Store.
Bundle/application identifier (proposed, not finalized): `cc.raneen.wajibati`.

## Status
- This branch prepares a **non-publishing, unsigned iOS validation workflow**.
- Do not merge, release, upload signing credentials, or publish without explicit authorization.
- iOS native files are generated by `npx cap add ios` in Codemagic; no generated Xcode project is committed by this workflow.
- App Store distribution requires legal organization verification, Apple Developer membership, signing configuration, App Store metadata, and review.
- Android packaging/signing remains a separate gate.
- Validate all auth, notifications, file exports and back navigation on real devices.
- Verify PWA service-worker registration does not interfere with native WebViews.
- Confirm privacy disclosures, student/guardian data processing, and reviewer-access accounts.

## Gates
1. Dependency lockfile synchronized with package.json.
2. `npm ci`, `npm run lint`, `npm run build`, `npm test` all pass.
3. Codemagic unsigned iOS build passes.
4. Native WebView and iPhone functional tests pass.
5. Signing, privacy, store listings and organizational verification completed.
6. Manual approval before merge, deployment or store submission.

## Caveats
- The configuration is a first-stage validation workflow only: no IPA, no App Store Connect upload.
- Capacitor dependencies must be installed and their exact versions locked before Codemagic can run `npm ci`.
- No Apple credentials or secret environment variables belong in Git.
