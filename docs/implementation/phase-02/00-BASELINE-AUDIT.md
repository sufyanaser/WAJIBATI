* `NoticesPage.tsx` (217 سطراً): إنشاء وبث الإعلانات المدرسية الموجهة حسب المرحلة أو الشعبة مع تتبع الأولوية.

* `src/lib/supabase.ts`: عميل Supabase الرسمي المعتمد على المفاتيح العامة المجهولة (`VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`).
