## 1. استراتيجية التحويل المعماري من Wireframe V2 إلى React

يهدف هذا المخطط إلى تحويل التصميم المفاهيمي والتفاعلي المثبت في `WAJIBATI-ADMIN-WIREFRAME-V2.html` ووثائق Phase 01 إلى مكونات React نقية وقابلة للصيانة، مع الحفاظ الكامل على التكامل الحي مع Supabase دون الاعتماد على بيانات ثابتة غير متصلة.

### مبادئ التحويل الصارمة:
1. **عدم إعادة كتابة التطبيق (Preserve Working Foundations):** البناء فوق الكود الحالي في `src/pages/admin/` و `src/hooks/useAdminSection.ts` و `src/styles.css` بدلاً من هدم ما تم اختباره والتحقق منه.
2. **التوافق التام مع المسارات القديمة (100% Non-Breaking Routing):** توحيد الشريط الجانبي في 6 أقسام مع إبقاء المسارات الفردية الحالية تعمل أو تحويلها بسلاسة عبر المعلمات أو المسارات المتوافقة.
3. **توحيد المكونات المشتركة (Shared Component Driven):** منع تكرار عناصر الجداول، الأزرار، والدرج الجانبي عبر بناء مكونات تأسيسية يعاد استخدامها في الأقسام الستة.
4. **المحافظة على صلاحيات Supabase RLS:** عدم تجاوز التحقق من صلاحيات المستخدم في أي عملية قراءة أو كتابة.

## 3. هندسة المكونات المشتركة التأسيسية (Shared Components Architecture)

لتحقيق الاتساق الصارم وتفادي التباين في واجهات الأقسام المختلفة، تُنشأ المكونات المشتركة التالية داخل `src/components/admin/`:

1. **`AdminDataTable.tsx`:**
   - جدول بيانات موحد يدعم الفرز اللحظي، الترقيم (Pagination)، البحث الفوري، وتحديد الصفوف عبر checkboxes.
   - يدعم التمرير الأفقي الآمن للشاشات الصغيرة دون تسريب الفائض للصفحة (`overflow-x: auto`).
2. **`RecordDrawer.tsx`:**
   - درج منزلق موحد يفتح من الجهة اليسرى (RTL) بعرض `min(540px, 100vw)`.
   - يتضمن مستشعر التغييرات غير المحفوظة (`dirty state guard`) وتنبيه المستخدم بمفتاح `Esc` والنقر الخارجي.
3. **`StatusBadge.tsx`:**
   - شارات دلالية موحدة للحالات: منشور (`green`)، مسودة (`gold`)، نشط (`green`)، موقوف (`red`)، ملغى (`danger`)، معلوماتي (`blue`).
4. **`ConfirmDialog.tsx`:**
   - صندوق حوار تأكيدي للعمليات الحساسة (الحذف، التعطيل الجماعي، نشر الشعبة بالكامل).
5. **`PageHeader.tsx`:**
   - ترويسة موحدة لكل صفحة تتضمن العنوان الرئيسي، النص التوضيحي، وحاوية الأزرار والإجراءات السريعة.
